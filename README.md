# История и философия науки

Материалы по лекциям Скворчевского К. А. и экзаменационным ответам.

Плейлист: https://www.youtube.com/playlist?list=PLthfp5exSWErXe0i-qc-Tohs4HwXJUgoQ

## Структура

- `answers/` - готовые экзаменационные ответы.
- `lectures/` - конспекты, транскрипты и исходные субтитры лекций.
- `tools/` - скрипты для конвертации YouTube `json3` субтитров в текст.

## Быстрый вход

- Все конспекты лекций одним файлом: `lectures/playlist_full_notes.md`.
- Индекс лекций: `lectures/playlist_notes_index.md`.
- Ответы на вопросы: `answers/README.md`.

## Важно по нумерации

Сейчас основная нумерация лекций идет по плейлисту: `playlist01` ... `playlist26`.

Старые файлы `lecture1` ... `lecture7` сохранены в `lectures/legacy_selected_links/`. Это ранняя рабочая нумерация по присланным ссылкам, где первая присланная лекция была третьей в плейлисте.

## Примечание по источникам

Конспекты сделаны по автосубтитрам YouTube `ru-orig`, без ручной сверки с аудио. У лекции 22 автосубтитры почти полностью распознаны как `[музыка]`, поэтому ее конспект ограничен доступными фрагментами.
