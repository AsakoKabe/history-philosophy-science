# Лекции

Материалы по плейлисту Скворчевского К. А. `История и философия науки`.

## Основные файлы

- `playlist_full_notes.md` - все 26 конспектов в одном файле.
- `playlist_notes_index.md` - индекс лекций с датами, ссылками и путями к материалам.
- `notes/` - отдельные конспекты по каждой лекции.
- `transcripts/` - транскрипты, разложенные по типам.
- `raw/` - исходные `info.json` и `ru-orig.json3` субтитры.
- `legacy_selected_links/` - старые рабочие файлы по первым присланным ссылкам.

## Транскрипты

- `transcripts/clean/` - чистый текст без таймкодов.
- `transcripts/timestamps/` - транскрипт с таймкодами.
- `transcripts/chunks/` - текст, разбитый на 5-минутные фрагменты.

## Лекция 22

Для лекции 22 дополнительно проверена альтернативная дорожка автосубтитров `ru`. Она практически совпала с `ru-orig`: часть записи распознана как `[музыка]`, а содержательный фрагмент распознан с сильными ошибками. В папке `transcripts/clean/` сохранен файл `playlist22_alt_ru_clean.txt` для сравнения.

## Нумерация

Основная нумерация соответствует порядку видео в плейлисте: `playlist01` ... `playlist26`.

`legacy_selected_links/` оставлена только для истории работы: там `lecture1` соответствует третьей лекции плейлиста, потому что пользователь изначально прислал ссылку с `index=3`.
